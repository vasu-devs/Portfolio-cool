The loop

  • Simulate: generated personas push the agent through difficult, off-script conversations.
  • Score: an LLM judge grades each run against per-metric thresholds you set.
  • Revise: the prompt is rewritten toward the failing metrics, then the loop runs again.

How it’s built

Simulation, judging, and revision are separate stages so each can be swapped. Progress streams over WebSockets; run history and word-level prompt diffs are persisted so every optimization cycle can be inspected later.

Where it stands

A working prototype. Simulated callers and judge scores are a fast way to compare prompt versions, not a substitute for listening to real calls, and I say so in the README.

Fork an AI conversation to explore a side thought, then merge it back without losing the main thread.

  • Next.js
  • TypeScript
  • Drizzle ORM
  • Neon Postgres
  • Vercel AI SDK
  • Groq
Public source · Chat tool
Source on GitHubWatch walkthrough
  • Next.js
  • TypeScript
  • Drizzle ORM
  • Neon Postgres
  • Vercel AI SDK
  • Groq

Public repository · demo video

The idea

Every message is a node. Forking from any message spawns a branch that inherits history up to that point, so you can chase a tangent without polluting the main thread. Merging is explicit, and the branch stays intact afterwards so you can keep exploring it.

Smart merging

  • Before a merge, Llama 3.3 on Groq summarises the branch, so the parent absorbs only the new insight, not the whole transcript.
  • Merge logic filters out shared history and appends only what is new.
  • Each merge is recorded as a distinct system event in the chat stream.

Tree navigation

A visual Git-style sidebar renders the whole conversation graph. Click any node to jump; each branch keeps its own history up to the fork point, so switching context is unambiguous.

How it’s built

Next.js App Router with Server Actions, the conversation tree in Neon Postgres through Drizzle, inference wired through the Vercel AI SDK, and full Markdown and LaTeX rendering in the chat.
