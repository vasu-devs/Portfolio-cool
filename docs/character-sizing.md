Character sizing

Heights use https://bleach-anime.com/en/character/ official TYBW profiles. Original Shikai Ichigo uses the pre-timeskip 174 cm profile; TYBW Ichigo uses 181 cm. Grimmjow uses the MASKED profile height, 186 cm (https://bleach.fandom.com/wiki/Grimmjow_Jaegerjaquez).

Standing alpha bounds normalize transparent sprite padding to 40 visible pixels per 181 cm. Hats, hair and stylized anatomy remain part of the artwork, so this is relative height matching, not anatomically exact manga artwork. Card art uses relative height scaling; thumbnail buttons remain uniform for usability. Gate scale is .64 times character height / 181, anchored at the threshold.
