# Awwwards typography selection

Browsed Awwwards' Free Fonts collection pages 1 and 2 on 2026-09-12. Reviewed entries including Ranade, Cabinet Grotesk, Clash Display and Satoshi. Selected Clash Display for its broad proportions and distinctive counters, with Satoshi for reading text and controls. This is a design judgment for this portfolio, not a claim that Awwwards ranks it the best font.

References:
- https://www.awwwards.com/awwwards/collections/free-fonts/
- https://www.awwwards.com/awwwards/collections/free-fonts/?page=2
- https://www.awwwards.com/inspiration/clash-display
- https://www.awwwards.com/inspiration/cabinet-grotesk-variable-font
- https://www.awwwards.com/inspiration/ranade
- https://www.fontshare.com/licenses/itf-ffl

Clash Display 500/600: opening line, section headings, project names and modal titles. Satoshi 400/500/700: paragraphs, metadata, controls. Existing Bleach wordmark and realm artwork retained. Removed chapter numbers, colored rules and the prior condensed, serif and handwritten treatments. Typical sizes: 34 px opening, 36 px section headings, 29 px project headings, 18 px body, 32 px modal title. Mobile scales down display sizes without reducing body below 16–17 px.

Fonts are served through the official Fontshare CDN using the CSS declarations in public/test/fontshare.css. No font binaries are redistributed in the public repository. License text captured in public/test/fonts/Fontshare-license.txt. CDN availability is a dependency; local Arial fallbacks remain available.

Verified all five font faces loaded, and page/modal fit at 390 and 1280 px in both themes. Selected layout inspected in-browser. This supersedes the rejected TYBW and handwriting experiments; remains a local preview.
